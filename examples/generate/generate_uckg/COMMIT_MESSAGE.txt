feat(uckg): add ETL pipeline for Incident Response training data

This commit introduces a curated data generation pipeline that bridges
the Unified Cybersecurity Knowledge Graph (UCKG) with GraphGen.

The goal is to generate "Incident Response" Q&A pairs (Symptom -> Solution).

Architecture Changes:
1. **Targeted Extraction**:
   - `extract_uckg_raw.py`: Queries Neo4j for specific triads:
     `CAPEC (Symptom) <-> ATT&CK (Category) <-> MITIGATION (Solution)`.
   - Ignores irrelevant nodes to keep the dataset focused.

2. **Data Cleaning & filtering**:
   - `filter_uckg_data.py`: Whitelists high-value properties (Description, Example, Technique) and discards metadata.
   - `clean_uckg_data.py`: Parses nested JSON-string properties from UCKG and polishes text formatting (e.g., bullets).

3. **GraphGen Integration**:
   - `load_to_graphgen.py`: Reconstructs the cleaned triads into GraphGen's internal KuzuDB storage.
   - `uckg_config.yaml`: Configured for 'atomic' generation to create rich, node-centric Q&A.

4. **Orchestration**:
   - `generate_uckg.sh`: Master script to run the full pipeline.
   - `inspect_kuzu.py`: Verification tool to prove graph connectivity.
